# Fake News Detection System

A machine learning-based Fake News Detection System built using Python and Flask. This project predicts whether a news article is real or fake using Natural Language Processing (NLP) techniques and a trained machine learning model.

## Features
- Detects fake and real news articles
- User-friendly web interface using Flask
- Machine learning model integration
- Text vectorization and prediction system
- Real-time news prediction

## Tech Stack
- Python
- Flask
- Machine Learning
- HTML
- CSS

## Project Status
This project is currently under development, and frontend improvements and additional features are being added continuously.

## Files Included
- `app.py` – Flask backend application
- `train_fake_news.py` – Model training script
- `model.pkl` – Trained ML model
- `vectorizer.pkl` – Text vectorizer
- `templates/` – Frontend templates
